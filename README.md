# FitnessApp 🚀

This is a basic Java application that introduces core programming concepts through a simulated fitness tracking program. The app includes string comparison logic and a basic diet tracker that checks and processes user input.

## 📁 Project Structure


## 📌 Features

- 🔠 **String Comparison:**  
  Compares strings for equality or similarity using Java string methods.

- 🥗 **Diet Tracker Input Validation:**  
  Checks if user input is a number (digit) or text (letter) to process dietary information safely.

## 💻 Technologies Used

- Java (JDK 17+)
- NetBeans IDE (or any Java-supporting IDE)
- Standard Java libraries

## 🛠️ How to Run

1. Clone or download the project.
2. Open the project in **NetBeans** or your preferred Java IDE.
3. Ensure all necessary `.java` files are in the `com.mycompany.fitnessapp` package.
4. Run the `FitnessApp.java` class.

## 📚 Learning Objectives

This project is great for beginners looking to:

- Understand Java class structures and object instantiation.
- Work with string methods and user input validation.
- Learn the basics of Java packaging and project setup.
